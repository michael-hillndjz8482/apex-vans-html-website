## Getting Started

Clone the project and enter its directory:

```bash
git clone https://github.com/michael-hillndjz8482/apex-vans-html-website.git
cd REPO
```

The HTML files may be opened directly in a browser. For a more reliable local preview, serve the repository with a development HTTP server.

Python provides a simple option:

```bash
python3 -m http.server 8000
```

Once the server is running, browse to `http://localhost:8000/`.

No. Viewing the site only requires a web browser. When previewing the files locally, you may optionally serve them through an HTTP server.

Start an HTTP server from the repository's root directory and open its address in your browser. Python's built-in server can be used for this purpose.

### Where should website configuration be changed?

The project does not define a separate settings system. Make website updates in the appropriate HTML project files.

### Where can I find the newest build?

### How can I troubleshoot a missing page?
